# Salvá — páginas legales

Política de privacidad y borrado de cuenta de la app **Salvá**, publicadas con
GitHub Pages porque Google Play y la pantalla de consentimiento de OAuth exigen
las dos como URLs públicas.

- <https://aletandil.github.io/salva-legal/privacidad.html>
- <https://aletandil.github.io/salva-legal/eliminar-cuenta.html>

El contenido se edita en el repo de la app, en `docs/legal/`, y se copia acá.
Ese repo es privado y GitHub Pages sobre repos privados es pago: por eso las
páginas viven separadas.
